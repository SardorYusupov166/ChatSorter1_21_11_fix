# ChatSorter 1.3.5 — Minecraft 1.21.11

Создан **mlpgod** для сервера **MigosMC**.

## Изменения 1.3.5

- Горячая клавиша настроек работает только в игре без открытых экранов. При наборе сообщения, поиске и работе в меню она не открывает настройки; удержанная при закрытии чата клавиша также не вызывает окно.
- При запуске и подключении к серверу выбрана вкладка «Все».
- Сначала Minecraft обрабатывает интерактивные сообщения, ссылки, команды и вставку текста. Только необработанный левый клик начинает перемещение или изменение размера окна.
- Чат по-прежнему можно перемещать за любую свободную точку окна. После перемещения координаты проверки кликов по тексту соответствуют его новому положению.
- При установленном дополнении MigosMC Rules появляется кнопка «Правила» слева сверху в открытом чате.
- Кнопка «Правила» оформлена палитрой ChatSorter и находится в одном верхнем ряду с вкладками чата.
- Дополнение MigosRules использует выбранную палитру ChatSorter и оформляет ею заголовки, разделы и кнопки.
- Исправлена версия в приветствии и имя артефакта GitHub Actions.

## Установка

Minecraft **1.21.11**, Java **21+**, Fabric Loader **0.18.0+**, Fabric API для 1.21.11.
Удалите старый JAR ChatSorter из `mods` и поместите новый. Конфигурацию удалять не нужно.
Для справочника добавьте второй файл `migos-rules-1.0.1.jar`.

## Сборка

Gradle **9.2.1**, JDK **21**: `gradle build`.
Результат: `build/libs/chatsorter-1.3.5.jar`.
В `.github/workflows` есть сборка через GitHub Actions, включая ручной запуск.

## Проверки

Сборка выполняется через Gradle 9.2.1 и JDK 21, в том числе workflow GitHub Actions. В текущей среде локальный Gradle блокируется при проверке Unix-сокетов Fabric Loom, поэтому эту ревизию нужно собрать через workflow. Полноценный запуск клиента и проверка на сервере не выполнялись.
